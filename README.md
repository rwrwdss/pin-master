# PinMaster

Программа чтобы парсить пины с Pinterest и публиковать их. Работает на компе через окошко с кнопками.

## Что нужно

Поставь Python 3.8 или новее. Потом в папке проекта выполни:

```
pip install -r requirements.txt
```

## Как запустить

Запускается главный файл:

```
python main.py
```

(Или `python qt_main_window.py` — откроет то же самое.)

Откроется окно. Там можно войти в Pinterest (через браузер сохраняются куки), потом парсить пины по запросу или со своих досок, смотреть результат в таблице. Ещё можно публиковать пины — картинку, название, описание, доску выбрать.

## Сборка под Mac

Если хочешь сделать приложение .app для macOS, запусти:

```
python build_macos_installer.py
```

Он соберёт программу в папку dist. На Apple Silicon (M1/M2) должно работать.

## Остальное

Конфиг лежит в config.json. Логи пишет в pinmaster.log. Если что-то сломалось — смотри в лог или в настройках программы.
