# Qt Интерфейс для Pinterest Parser

## Структура отображения информации об аккаунте

Информация об аккаунте отображается **в главном окне приложения** в специальном виджете вверху:

```
┌─────────────────────────────────────────────────┐
│  Pinterest Parser                    [Аккаунт] │
├─────────────────────────────────────────────────┤
│  ┌─ Информация об аккаунте ─────────────────┐  │
│  │ 👤 username                               │  │
│  │ Имя: Display Name | Пинов: 100 | Доск: 5 │  │
│  │ [Обновить информацию]                     │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  ┌─ Парсинг ────────────────────────────────┐  │
│  │ Тематика: [________________] [Парсить]  │  │
│  │ [Парсить мои пины] [Парсить мои доски]   │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  ┌─ Результаты ─────────────────────────────┐  │
│  │                                           │  │
│  │                                           │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

## Как это работает

1. **При запуске приложения:**
   - Загружается конфигурация из `config.json`
   - Если `enable_login: true`, автоматически получается информация об аккаунте
   - Информация отображается в виджете "Информация об аккаунте" вверху главного окна

2. **Виджет информации об аккаунте:**
   - Показывает имя пользователя (username)
   - Отображает дополнительную информацию (имя, количество пинов, досок)
   - Кнопка "Обновить информацию" для ручного обновления

3. **Меню "Аккаунт":**
   - "Обновить информацию" - обновляет данные об аккаунте
   - "Выйти" - очищает информацию об аккаунте

## Запуск Qt-интерфейса

```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python qt_main_window.py
```

## Интеграция с парсером

Информация об аккаунте получается через метод `get_account_info()` класса `PinterestSeleniumParser`:

```python
account_info = parser.get_account_info()
# Возвращает:
# {
#     'username': 'username',
#     'profile_url': 'https://ru.pinterest.com/username/',
#     'pins_url': 'https://ru.pinterest.com/username/_pins/',
#     'boards_url': 'https://ru.pinterest.com/username/_boards/',
#     'display_name': 'Display Name',  # опционально
#     'pins_count': '100 пинов',       # опционально
#     'boards_count': '5 досок'        # опционально
# }
```
